# Pencil Media Solutions

A high-performance web interface built with Next.js, TypeScript, and MUI

## Key Features
- Scalable architecture with reusable components.
- Dynamic data management using constant files.
- Fully responsive UI built with Tailwind CSS.

## Tech Stack
- Next.js (App Router)
- Tailwind CSS & Material UI
- TypeScript

## Getting Started
```bash
npm install
npm run dev
